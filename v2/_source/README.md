# โค้ดต้นฉบับ Meemon V2

โค้ด React และ TypeScript ของ V2 อยู่ในโฟลเดอร์นี้ทั้งหมด ส่วนไฟล์ที่
GitHub Pages เปิดใช้งานจริงอยู่ที่โฟลเดอร์แม่ `v2/`

คำสั่งสำหรับพัฒนา:

```bash
npm install
npm run dev
```

เมื่อแก้ไขเสร็จ ให้สร้างไฟล์ static และนำไปวางใน `v2/` ด้วย:

```bash
npm run publish:static
```

สคริปต์เผยแพร่จะอัปเดตเฉพาะไฟล์ของ V2, หน้าสารบัญ legacy และภาพแชร์
โดยไม่แตะโฟลเดอร์แอปเก่า

## ไฟล์หลัก

- `products.json` — ข้อมูลเต็มแบบมีโครงสร้าง
- `products.csv` — ตารางสินค้าสำหรับนำเข้าโปรแกรมอื่น
- `shop.json` — ข้อมูลร้านค้า
- `image_manifest.json` — URL ต้นฉบับและตำแหน่งไฟล์รูปในเครื่อง
- `outputs/019fac05-c38a-7132-b675-1a676fb2f644/shopee_king_6914_products.xlsx` — สมุดงาน Excel
- `products/<item_id>/data.json` — ข้อมูลแยกรายสินค้า
- `products/<item_id>/images/` — รูปภาพแยกรายสินค้า
